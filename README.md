# iAnime

PWA to track favorite anime, browse the release calendar, and read news.

## Stack

- **Frontend:** React 18, TypeScript, Tailwind CSS, PWA (vite-plugin-pwa)
- **Backend:** FastAPI monolith (API + built frontend)
- **Database:** PostgreSQL (Gigalixir prod) / SQLite (local dev)
- **External APIs:** AniList, Jikan, AniNewsAPI

## Features

- Home with popular anime and advanced filters (title, genre, status, seasons, score, platform)
- Filter panel hidden by default, expandable with a tap
- Favorites synced to account
- Weekly release calendar (ongoing favorites)
- Anime detail with full description and EN/IT toggle (on-demand translation)
- News aggregated from multiple sources
- Account with password change
- Installable PWA with custom icon (poster + stylized calendar "i")

## Prerequisites

- Node.js 20+
- Python 3.12+
- [Gigalixir](https://gigalixir.com) account (production deploy)

## Local development

### 1. Backend

```bash
cd server
python -m venv .venv
.venv\Scripts\activate        # Windows
pip install -r requirements.txt
copy ..\.env.example .env     # set DEFAULT_SEED_PASSWORD
alembic upgrade head
python -m app.seed
uvicorn app.main:app --reload --port 8000
```

### 2. Frontend

```bash
cd client
npm install
npm run dev
```

Open http://localhost:5173 — the proxy forwards `/api` to `:8000`.

### Login

Seed user credentials are set via `DEFAULT_SEED_USERNAME` and `DEFAULT_SEED_PASSWORD` in `.env`.

Public registration is disabled; use the **Account** page after login to change your password.

## Deploy on Gigalixir

```bash
pip install gigalixir
gigalixir login
gigalixir create -n ianime
gigalixir pg:create --free -a ianime
gigalixir config:set JWT_SECRET=your-secret-key -a ianime
gigalixir config:set DEFAULT_SEED_USERNAME=your-username -a ianime
gigalixir config:set DEFAULT_SEED_EMAIL=your@email.local -a ianime
gigalixir config:set DEFAULT_SEED_PASSWORD='your-secure-password' -a ianime
gigalixir config:set SEED_DEFAULT_USER=true -a ianime
gigalixir config:set ALLOW_REGISTRATION=false -a ianime
gigalixir git:remote -a ianime
npm run deploy
```

`npm run deploy` automatically bumps the build in `client/src/version.json`, creates a commit, and pushes to Gigalixir.

For manual minor/major bumps: `npm run version:minor` / `npm run version:major`.

Manual push (not recommended — does not update the version):

```bash
git push gigalixir main
```

### PWA icon

Icons live in `client/public/icons/`:

| File | Use |
|------|-----|
| `icon.png` | Favicon and header logo |
| `icon-192.png` | PWA manifest (192×192) |
| `icon-512.png` | PWA manifest, Apple Touch Icon (512×512) |

The manifest is generated by `vite-plugin-pwa` in `client/vite.config.ts`. After an icon update, reinstall the PWA on the device if the home screen icon does not refresh right away.

## Environment variables

| Variable | Description |
|----------|-------------|
| `DATABASE_URL` | Auto on Gigalixir; SQLite in dev |
| `JWT_SECRET` | JWT secret key |
| `DEFAULT_SEED_USERNAME` | Seed username |
| `DEFAULT_SEED_PASSWORD` | Seed password (first creation only) |
| `DEFAULT_SEED_EMAIL` | Seed email placeholder |
| `SEED_DEFAULT_USER` | `true` to create user on startup |
| `ALLOW_REGISTRATION` | `false` in production (registration disabled) |
| `CLIENT_URL` | Frontend URL (CORS in dev) |
| `VITE_API_URL` | `/api` in production |
| `LIBRETRANSLATE_URL` | LibreTranslate mirror (default `https://translate.fedilab.app`) |
| `LIBRETRANSLATE_API_KEY` | Optional, only if the mirror requires it |

### Description translation (anime detail)

- Default: original AniList text (English)
- **IT** toggle: translation via LibreTranslate (public mirror, no signup)
- Client cache 7 days (`localStorage` + React Query)
- `/api/descriptions/translate` is JWT-protected; home and detail require login

Alternative mirrors if the default is offline: `https://translate.cutie.dating`, `https://libretranslate.de`

## Gigalixir free tier limits

- No sleep (app always on)

## Notes

- IT dub/subs: heuristic from AniList links, not official geo-IT data
- Streaming platforms are indicative (AniList does not filter for Italy)
- Do not commit `.env` with real passwords
- `DEFAULT_SEED_PASSWORD` does not update the password if the seed user already exists: use the Account page
